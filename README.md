# Portfolio — Jekyll site for GitHub Pages

A  Jekyll portfolio site, showcasing professional experience and key projects.

## What's in here

```
├── _config.yml              ← site settings: 
├── index.html                ← homepage (hero, about, experience, skills, contact)
├── _projects/                ← one file per case study — this is what shows in "Projects"
|
├── _layouts/                  ← page templates 
├── _includes/                 ← shared nav/header/footer snippets
├── assets/css/style.css       ← all styling in one file
└── .github/workflows/jekyll.yml  ← auto-builds & deploys on every push
```
